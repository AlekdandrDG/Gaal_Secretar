# Бот в Telegram: токен и ваш ID

Здесь вы создадите бота в Telegram — это «лицо» Гэл, окно, в которое вы будете ей писать. Займёт 5 минут, всё делается в самом Telegram, ничего скачивать не нужно.

Что получится в итоге — две строчки, которые спросит установщик:

| Что | Пример | Зачем |
|---|---|---|
| Токен бота | `123456789:AAHdN8J2K4m5N6o7P8q9R0s1T2u3V4w5X6y` | чтобы программа могла управлять вашим ботом |
| Ваш Telegram ID | `123456789` | чтобы бот отвечал только вам |

> **Токен** — это длинная строка из букв и цифр, пароль для программ. Отличие от обычного пароля одно: его вводит не человек, а программа. Всё остальное так же — кто знает токен, тот управляет ботом.

---

## Часть 1. Создаём бота

### Шаг 1. Найдите @BotFather

1. Откройте Telegram.
2. Нажмите на поиск (лупа сверху).
3. Введите `BotFather`.
4. В результатах найдите аккаунт с именем **BotFather** и синей галочкой рядом с именем.

**Важно.** Ботов с похожими именами много, и почти все — подделки. Настоящий только один: username ровно `@BotFather` и синяя галочка. Если галочки нет — это не он, закройте и ищите дальше.

Если сомневаетесь, откройте ссылку: https://t.me/BotFather — она ведёт на настоящий аккаунт.

### Шаг 2. Начните разговор

1. Откройте чат с BotFather.
2. Нажмите кнопку **Start** (или **Запустить**) внизу экрана.
3. В ответ придёт длинный список команд — это нормально, читать его не нужно.

### Шаг 3. Создайте нового бота

1. Отправьте сообщение: `/newbot`
2. BotFather спросит имя бота (name).

### Шаг 4. Придумайте имя

Имя — это то, что вы увидите в списке чатов. Любые буквы, русские тоже, можно с пробелами.

Например: `Гэл` или `Мой секретарь`.

Отправьте имя одним сообщением.

### Шаг 5. Придумайте username

Дальше BotFather попросит username — это адрес бота, вроде `@moy_secretar_bot`.

Правила жёсткие:

- только латинские буквы, цифры и знак `_`;
- **обязательно должен заканчиваться на `bot`**;
- должен быть свободен — если такой уже занят, BotFather напишет `Sorry, this username is already taken` и попросит другой.

Короткие красивые имена давно разобраны. Добавьте что-нибудь своё: фамилию, год, случайные цифры. Например: `gael_ivanov_2026_bot`.

Отправьте username одним сообщением и, если он занят, просто пришлите следующий вариант.

### Шаг 6. Заберите токен

Когда username подошёл, BotFather пришлёт поздравление и в тексте — строку вида:

```
123456789:AAHdN8J2K4m5N6o7P8q9R0s1T2u3V4w5X6y
```

Это и есть токен бота. Как он устроен: несколько цифр, двоеточие, затем длинный набор букв, цифр, иногда дефисов и подчёркиваний.

1. Нажмите на эту строку — Telegram скопирует её целиком.
2. Сохраните её туда, откуда сможете скопировать при установке: заметки, менеджер паролей, черновик.

**Копируйте всю строку вместе с цифрами до двоеточия.** Частая ошибка — скопировать только вторую половину. Такой токен работать не будет.

> ⚠️ **Токен — это пароль от вашего бота.** Кто его получит, тот сможет писать от имени бота и читать все сообщения. Не публикуйте его, не отправляйте в чаты, не показывайте на скриншотах.
>
> Если токен всё-таки утёк: откройте BotFather, отправьте `/revoke`, выберите бота — старый токен перестанет работать, и вам выдадут новый.

---

## Часть 2. Узнаём свой Telegram ID

Установщик спросит ваш числовой ID. Он нужен, чтобы Гэл отвечала только вам: посторонний найдёт вашего бота в поиске, напишет ему — и получит отказ.

### Шаг 1. Найдите @userinfobot

1. В поиске Telegram введите `userinfobot`.
2. Откройте бота с username `@userinfobot`.

### Шаг 2. Спросите свой ID

1. Нажмите **Start** (**Запустить**).
2. Бот сразу ответит короткой карточкой с вашими данными.

### Шаг 3. Найдите строку Id

В ответе будет строка вроде:

```
Id: 123456789
```

Нужно только число — обычно 9-10 цифр. Скопируйте и сохраните рядом с токеном.

**Не путайте** с полем `@username` — это имя вида `@ivanov`, установщику оно не нужно. Нужно именно число.

Если такой бот не находится или молчит, подойдёт любой другой бот, показывающий ID (в поиске их несколько по слову «userinfo»). Число будет одно и то же — ID у вашего аккаунта только один.

---

## Что должно быть на руках

Перед запуском установщика проверьте, что у вас записаны:

- [ ] токен бота — длинная строка с двоеточием;
- [ ] ваш Telegram ID — число;
- [ ] username бота (`@..._bot`) — чтобы потом найти бота в поиске.

---

## Если что-то пошло не так

**BotFather пишет «Sorry, this username is already taken».**
Username занят кем-то другим. Придумайте другой и отправьте его следующим сообщением — начинать заново не нужно. Помните: окончание `bot` обязательно.

**Установщик говорит, что токен неверного формата.**
Скорее всего, скопировалась только часть строки или прицепился лишний пробел. Вернитесь в чат с BotFather, найдите сообщение с токеном, нажмите на строку целиком, чтобы скопировать. Если сообщение потерялось — отправьте `/mybots`, выберите своего бота и найдите пункт про токен (называется примерно «API Token»).

**Потерял токен / боюсь, что его увидели.**
Откройте BotFather, отправьте `/revoke`, выберите бота. Старый токен станет недействительным, придёт новый. Если бот уже установлен на сервере, после смены токена его нужно прописать заново.

**Бот не отвечает после установки.**
Проверьте, что установщику вы дали ID именно своего аккаунта. Если ID чужой, бот будет молчать в ответ на ваши сообщения — так и задумано. Узнайте ID заново через @userinfobot и сравните с тем, что вводили.
