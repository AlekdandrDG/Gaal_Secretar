# Инструкции по установке Гэл

Гэл живёт на сервере и общается с вами в Telegram. Чтобы она заработала, нужно дать ей доступ к нескольким сервисам: каждый выдаёт свой ключ — длинную строку из букв и цифр, пароль для программ.

Установщик спросит эти ключи по очереди и не будет ждать, пока вы их добываете. **Получите всё заранее** и держите под рукой — в заметках, менеджере паролей или черновике письма.

Ничего программировать не нужно. Всё делается мышкой в браузере и в Telegram.

Идите сверху вниз — это тот же порядок, в котором ключи спросит установщик.

| № | Инструкция | Что получите | Время | Обязательно |
|---|---|---|---|---|
| 1 | [claude-subscription.md](claude-subscription.md) | Подписку Claude — «мозги» Гэл, и вход на сервере | 10-15 мин | да |
| 2 | [telegram-bot.md](telegram-bot.md) | Токен бота и свой Telegram ID | 5 мин | да |
| 3 | [deepgram.md](deepgram.md) | Ключ Deepgram — расшифровка голосовых | 10 мин | да |
| 4 | [todoist.md](todoist.md) | Токен Todoist — задачи | 5 мин | да |
| 5 | [google-setup.md](google-setup.md) | Доступ к Google Календарю — встречи и билеты | 20-30 мин | нет |
| 7 | [mcp-cli-setup.md](mcp-cli-setup.md) | Технические детали связи с Todoist | — | справочно |

Пункты 1-4 нужны обязательно: без любого из них Гэл не запустится или потеряет важную часть себя.

Пункт 5 необязателен. Без него Гэл работает полностью, только не ставит события в календарь и не разбирает билеты. Подключить можно позже в любой день. Это самая длинная инструкция — если сегодня нет получаса, спокойно пропускайте.

Пункты 6-7 — для тех, кто хочет разобраться в устройстве или чинит поломку. При обычной установке они не нужны: установщик делает всё сам.

## Что должно быть на руках перед установкой

- [ ] активная подписка Claude (Pro или Max);
- [ ] токен бота Telegram — строка вида `123456789:AAH...`;
- [ ] ваш Telegram ID — число;
- [ ] API-ключ Deepgram — длинная строка букв и цифр;
- [ ] API-токен Todoist — длинная строка букв и цифр;
- [ ] *(по желанию)* JSON-файл Google, скачанный на компьютер;
- [ ] VPS с Ubuntu 24.04 — см. [vps-beget.md](vps-beget.md) или [vps-justhost.md](vps-justhost.md);
- [ ] доступ к серверу по SSH — см. [terminal-ssh.md](terminal-ssh.md).

Ещё установщик спросит ваш **часовой пояс** — просто выберите город из предложенного списка. Готовиться заранее не нужно. Нужен он, чтобы вечерние отчёты приходили вечером по вашему времени, а не по времени сервера.

## Общие правила безопасности

- **Ключ — это пароль.** Не публикуйте ключи, не отправляйте в чаты и не показывайте на скриншотах.
- **Не ведите трансляцию экрана во время установки.** Ключи видны в терминале, пока вы их вставляете.
- **Если ключ утёк** — не паникуйте: в каждом сервисе его можно отозвать и выпустить новый. Как именно, написано в конце соответствующей инструкции.
- **Сохраните ключи там, где найдёте их снова.** Некоторые сервисы показывают ключ ровно один раз.
