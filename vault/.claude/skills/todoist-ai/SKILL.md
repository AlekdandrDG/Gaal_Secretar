# todoist-ai

Todoist integration via mcp-cli.

## CRITICAL

**ALWAYS use mcp-cli. DO NOT use MCP tools directly.**

```bash
# Today's tasks
todoist-cli find-tasks-by-date '{"startDate": "today"}'

# Create task
todoist-cli add-tasks '{"tasks": [{"content": "Task", "dueString": "tomorrow", "priority": 2}]}'

# Complete task
todoist-cli complete-tasks '{"ids": ["task_id"]}'

# Overview
todoist-cli get-overview '{}'
```

## Description

A set of tools to connect to AI agents, to allow them to use Todoist on a user's behalf. Uses mcp-cli wrapper for stable connections.
